# BRIEF — краткое направление продукта

Каноническое ТЗ: [`MASTER_SPEC.md`](MASTER_SPEC.md). Источник направления —
`CODEVINCI_ATLAS_PRODUCT_BRIEF_v0.3.md`.

## Что это

CodeVinci Atlas — самостоятельный публичный open-source продукт и self-hosted
инструмент одного владельца. Он автоматизирует процесс: идея владельца →
Codex Planner формирует этап → Claude/Codex Builder реализует → Atlas собирает
diff/проверки/evidence → независимый Codex Reviewer проверяет → один цикл
исправления → разрешённый PR/merge → сохранение состояния → следующий этап.

## Память проекта

Не бесконечный чат, а versioned Brief, Spec, Map, Git, Work Orders, decisions,
checkpoints и evidence. Сессии Codex/Claude — сменяемые исполнительские ресурсы.

## Главные риски

- Продуктовый: Atlas может ускорить плохое решение → автоматизация не заменяет
  зафиксированную цель, независимый review, фактический запуск и границы владельца.
- Технический: безопасная изоляция профилей, выбор без копирования credentials,
  продолжение после смены профиля/сессии, классификация rate limit, один writer.
  **Это доказывает VP-0.**

## Формат

BUILD через VP-0…VP-9. WIP=1 на уровне продукта, один writer на worktree.
Каждый VP даёт законченный проверяемый результат и не расширяет молча scope
следующего.

## Приёмка

Сначала synthetic repo, затем реальный проект File Atelier (VP-9), выбранный
владельцем как небольшое полезное вертикальное улучшение.
